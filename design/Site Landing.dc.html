macOS menu bar utility

Pin your scripts to the menu bar.

pinchos runs the commands you give it and pins their output where you can see it. Quiet while everything is healthy — unmissable the moment something fails.

01 · config

One plain-text file

Every item is a few lines of json — a title, a command, a schedule. Edit it in anything; pinchos picks up the change. There is no settings window.

02 · signal

Quiet when healthy

Healthy items are just text. Failure speaks in place — ⚠︎ in the bar, the exact cause and a copy button one click away. Stale output gets a ~.

03 · footprint

Native and tiny

Real NSStatusItems and real NSMenus. System typography, template icons, zero idle motion, no dock icon. It behaves like a built-in menu extra.

Get pinchos

Clone and build with the Swift toolchain, or start from the README — it covers install, the config format, and every marker pinchos can show.
